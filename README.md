# Eurasian tree sparrow acoustic dataset code

Version **1.0.0** provides recording acquisition, data processing, validation
and figure-reproduction tools. Use it with the companion data package **1.0.0**.

Start with [the English guide](code/README.md) or
[中文使用说明](code/README.zh-CN.md). Each component documents its dependencies,
inputs, commands and scientific interpretation boundaries.

- Data checks, exact reconstruction of 2,556 syllables and Raven export.
- Acoustic features, clustering assistance and matched internal assessments.
- Six manuscript figures, including 27 main-form families in Figure 5 and the
  Single 08 main-form/variant comparison in Figure 6.

The software is archived on Zenodo at [10.5281/zenodo.22879603](https://doi.org/10.5281/zenodo.22879603).
The companion acoustic dataset is available at [10.5281/zenodo.22878786](https://doi.org/10.5281/zenodo.22878786).
Field recordings are supplied separately from this code package.

Original code uses MIT. Third-party code, numerical and image assets, maps
and fonts retain the terms in
[THIRD_PARTY_NOTICES.md](code/THIRD_PARTY_NOTICES.md).

Release attachments provide the software ZIP, download instructions and
checksums. Run `python -B code/verify_package.py` before installation.
