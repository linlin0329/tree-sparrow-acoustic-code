# 树麻雀数据集配套代码

当前代码版本 **1.0.0**，配套数据包 **1.0.0**。两包可一起解压为同级 `data/` 与 `code/`；
也可通过参数指定其他数据位置。

正式发布入口：[数据包](https://doi.org/10.5281/zenodo.22878786)、[代码包](https://doi.org/10.5281/zenodo.22879603)。
`../data/`开头的链接用于同级解压后的本地数据包；在线浏览代码仓库时，请使用上方数据DOI。

代码包包含三个组件：

- [采集](acquisition/README.zh-CN.md)：完整30 s录音、固定BirdNET模型检测、MP3留存、安装与回滚。
- [数据分析](analysis/README.md)：数据检查、音节精确重切、Raven导出、特征和配套分析。
- [图件复现](figures/README.zh-CN.md)：六幅论文图的源码和必要输入。

各组件使用独立环境，安装与命令见对应说明。建议先检查数据，再按需要运行分析。
138份分析WAV对应116条原始录音，支持2,556个音节按整数帧精确提取；原始MP3中的
精确裁剪坐标未核实，提取时以分析WAV及其标注为参照。

安装或修改代码前，可执行 `python -B verify_package.py` 核对文件完整性。
研究者已报告采集组件在Pi上运行正常；具体版本兼容条件及安装检查见采集组件说明。

原创代码采用[MIT](LICENSE)，研究者数值输入及图件素材采用CC BY 4.0；第三方与派生
代码、地图和字体保留原条款，详见[许可与署名](THIRD_PARTY_NOTICES.md)。
原始音频和模型权重不放在代码包内，录音与标注见[独立数据包](../data/README.md)。

## 图件与标签评估

图5为全部27个类型族各展示一个主体音节：Single 14例、Double 6例、Triple 7例，
按三行九列排列，时间范围0–0.7 s。图6展示Single 08主体／变体两例，时间范围0–0.4 s。
两图合计使用29个唯一示例的STFT数组；布局及输入检查见[图件复现说明](figures/README.zh-CN.md)。

Single／Double／Triple分别为1,153／768／635个音节、14／6／7个类型族、20／9／12个末级类别，
合计2,556个音节、27个类型族、41个末级类别。标签内部评估使用与全部2,556个配套提取区间
及标签匹配的数值输入，并包含127对结构内类型族比较。分折仅在训练折缺少应覆盖类别时，
按固定递增种子寻找可行划分；先检查类别覆盖再拟合与评分，不按分数挑选结果。
完整分折身份与尝试记录由评估程序输出。具体方法及解释限制见
[分析组件](analysis/README.md)及[数据评估说明](../data/validation/label_assessment/README.md)。
波形／坐标标识为`data_version=1.0.0`，标签标识为`1.0.0`。
