# 树麻雀数据集配套代码

当前版本 **1.0.1**，对应数据包 **1.0.1**。两包可一起解压为同级 `data/` 与 `code/`；
也可通过参数指定其他数据位置。代码包包含三个组件：

- [采集](acquisition/README.zh-CN.md)：完整30 s录音、固定BirdNET模型检测、MP3留存、安装与回滚。
- [数据分析](analysis/README.md)：数据检查、音节精确重切、Raven导出、特征和配套分析。
- [图件复现](figures/README.zh-CN.md)：六幅论文图的源码和必要输入。

各组件使用独立环境，安装与命令见对应说明。建议先检查数据，再按需要运行分析。
138份分析WAV对应116条原始录音，支持2,556个音节按整数帧精确提取；原始MP3中的
精确裁剪坐标未核实，提取时以分析WAV及其标注为参照。

安装或修改代码前，可执行 `python -B verify_package.py` 核对文件完整性。
研究者已报告采集组件在Pi上运行正常；具体版本兼容条件及安装检查见采集组件说明。

原创代码采用[MIT](LICENSE)，研究者数值输入及图件素材采用CC BY 4.0；第三方与派生
代码、地图和字体保留原条款，详见[许可与署名](THIRD_PARTY_NOTICES.md)。
原始音频和模型权重不放在代码包内，录音与标注见[独立数据包](../data/README.md)。

## 1.0.1分类更正

包版本为1.0.1；波形/坐标`data_version`仍为1.0.0；标签为`sdt-taxonomy-r2-2026-09-24`。原Triple05的74音节整体改为Double05，并沿原family身份重排相关编号。当前Single/Double/Triple为1153/768/635音节、14/6/7族、20/9/12叶，总数2556/27/41不变。

默认标签评估使用R1改界输入＋当前标签，结构内比较为127对。分折只在训练折缺少应覆盖类别时，按固定递增seed寻找可行划分；先检查分折再评分，不按分数挑seed。本版本仅nonnoise family第5次重复从seed146换147，分折身份与尝试记录均输出。

43叶输入的人工精炼stage保留历史2560→2556筛选及原研究边界，额外明确执行74条结构更正，不能用于覆盖R1两条改界。当前发布音节重建与Raven表以相配`data/metadata/`为准。历史map单独保留，默认使用R2合成map。
