# 六幅论文图件复现

本组件随代码 **1.0.0** 提供绘图程序、源表、地图、研究者设备照片和声谱数组，
配套数据包 **1.0.0**。波形／坐标标识为1.0.0，标签标识为`1.0.0`。
安装、命令及图号对应见 [英文说明](README.md)。使用独立 Python 3.13 环境，
数据参数指向含 `metadata/`、`audio/analysis_clips/` 和 `annotations/raven/` 的数据包根目录。
输出目录应新建在输入之外。`--check-only` 只检查输入关联。

图5为全部27个类型族各展示一个主体音节：Single 14例、Double 6例、Triple 7例，
按三行九列依次排列S01–S14、D01–D06、T01–T07，时间范围0–0.7 s。
绘图区高/宽统一为1.19877049；每行共用一条0 kHz横线，6.3 pt类型族编号置于横线下方。
共享灰度图例和经校准的0.4 s时间比例尺置于网格底部；比例尺不改变0–0.7 s显示窗口，
示例之间的间隔只用于排版，不表示自然鸣唱时序。

图6展示Single 08主体／变体两例及0–0.4 s范围。
两图均为0–16 kHz，灰度范围−45至0 dB，相对于各面板显示频带内的峰值。
输入检查会按整数帧从分析WAV提取29个唯一示例（图5为27例、图6为2例），
与配套STFT数组核对，相对容差为0、绝对容差为1e-10 dB。
图4展示Single／Double／Triple的14／6／7个类型族及20／9／12个末级类别。
图5和图6使用配套分析WAV及其标签，数值源数据和输入检查确定每个示例。
六图输出PDF、SVG及400 dpi PNG。地图点是村级参考位置，不是逐台设备GPS。
