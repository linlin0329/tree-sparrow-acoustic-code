# 六幅论文图件复现

本组件随代码 **1.0.0** 提供绘图程序、源表、地图、研究者设备照片和声谱数组。
安装、命令及图号对应见 [英文说明](README.md)。使用独立 Python 3.13 环境，
数据参数指向含 `metadata/`、`audio/analysis_clips/` 和 `annotations/raven/` 的数据包根目录。
输出目录应新建在输入之外。`--check-only` 只检查输入关联。

图5展示三行四列的12个主体音节（0–0.5 s）；图6展示Single 08主体与变体（0–0.4 s）。
两图均为0–16 kHz，灰度范围−45至0 dB，相对于各面板显示频带内的峰值。
运行会按整数帧从分析WAV提取14例，与配套声谱数组核对，不更改音频或标签。
六图输出PDF、SVG及400 dpi PNG。地图点是村级参考位置，不是逐台设备GPS。
