# Natural Earth provincial boundary data

The Gansu outline in `gansu_boundary.geojson` is extracted from Natural Earth
1:10,000,000 Admin 1 – States, Provinces, version 5.1.1.

Natural Earth places its vector and raster map data in the public domain.
Its terms permit reuse, modification and redistribution in electronic and
printed materials, including commercial use, without permission or a fee.

- [Official terms of use](https://www.naturalearthdata.com/about/terms-of-use/)
- [Dataset page](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-1-states-provinces/)
- [Source repository licence](https://github.com/nvkelso/natural-earth-vector/blob/master/LICENSE.md)

Suggested credit: **Made with Natural Earth.**

`gansu_source_manifest.json` identifies the source archive, selected feature,
coordinate system and file checksums. The outline provides provincial
geographic context at the source cartographic scale. The province's reported
land area is documented separately from the boundary geometry in that manifest.
